# ApplyFlow Desktop 2.3.13 — Hide Jobright “Apply Now” cards

## What changed

**Hide unsupported Jobright list cards**
- On Jobright recommend and other search lists, ApplyFlow removes cards whose apply button is **Apply Now**, referral-only, or unrecognized.
- Only **Apply with Autofill** cards stay visible in the Jobs tab.
- Hiding re-runs as results load, scroll, or refresh, using the same label-based classification as the Autofill-only processing filter (not button color or screen coordinates).

## Installation

Quit ApplyFlow, then run `ApplyFlow-Setup-2.3.13.exe` (or `ApplyFlow-2.3.13-portable.exe`).
